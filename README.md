# GK-Agent-download

本仓库用于存放 **GK Agent** 的历史版本发布包，通过 [GitHub Releases](https://github.com/gopk-core/GK-Agent-download/releases) 归档各版本安装文件（完整包、代码包、资源包等），方便按版本下载和校验。

这里不是应用源码仓库，也不提供在线构建。当前公开版本为 **5.85**。

为减轻官方服务器带宽压力，网站下载与应用更新请使用 [ghproxy.net](https://ghproxy.net/) 加速获取本仓库发行包，例如：

- 完整安装包：https://ghproxy.net/https://github.com/gopk-core/GK-Agent-download/releases/download/v5.85/GK-Agent-5.85-release.apk
- 代码包：https://ghproxy.net/https://github.com/gopk-core/GK-Agent-download/releases/download/v5.85/GK-Agent-5.85-code.apk
- 资源包：https://ghproxy.net/https://github.com/gopk-core/GK-Agent-download/releases/download/v5.85/GK-Agent-resources-rootfs-84c31e54cfc0daf3.gkr

请对照发行版中的 `.sha256` 文件校验下载结果。
